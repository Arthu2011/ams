PYTHON

Qual a diferença entre Listas e Tuplas?

A principal diferença entre listas e tuplas em Python é a mutabilidade. As listas são mutáveis (você pode alterar, adicionar ou remover itens), enquanto as tuplas são imutáveis. Elas também diferem na sintaxe, uso e desempenho.

O que é o escopo local vs. global?

escopo define a região do código onde uma variável é visível e pode ser acessada. O escopo local é restrito ao bloco ou função onde a variável é criada, enquanto o escopo global abrange todo o código ou arquivo principal, podendo ser acessado de qualquer lugar.

O que são funções Lambda?

Uma função lambda em Python é uma função anônima de linha única. Em vez de usar a palavra-chave def para declarar uma função formal, você usa lambda para criar operações rápidas e temporárias que são avaliadas e retornadas imediatamente.

O que é a PEP 8?

O PEP 8 é o guia oficial de estilo de código para a linguagem Python. Seu principal objetivo é estabelecer padrões para tornar os códigos mais legíveis, consistentes e fáceis de manter por qualquer desenvolvedor.

O que são Dicionários em Python?

Dicionários são estruturas de dados mutáveis e flexíveis que armazenam informações em pares chave-valor. Parecem uma lista telefônica, onde você busca por uma informação específica (a chave, como um nome) e obtém o dado correspondente (o valor, como o número de telefone), o que permite buscas extremamente rápidas.

JAVA

O que é Java e para que serve?

O Java é uma das linguagens de programação e plataforma de computação mais populares e utilizadas no mundo. Ele permite criar softwares robustos e seguros que podem ser executados em praticamente qualquer dispositivo.

O que é a portabilidade "Escreva uma vez, rode em qualquer lugar" (WORA)?

O acrônimo WORA (Write Once, Run Anywhere, ou "Escreva uma vez, rode em qualquer lugar") é o princípio fundamental do Java que permite que o mesmo código compilado seja executado em qualquer sistema operacional (como Windows, Linux ou macOS) sem a necessidade de reescrever ou recompilar o código para cada ambiente.

O que é Orientação a Objetos (POO)?

A Programação Orientada a Objetos (POO) é um paradigma de programação que organiza o código simulando o mundo real em "objetos". Em Java, o código é estruturado em torno desses objetos, que contêm dados (atributos) e comportamentos (métodos) para criar sistemas mais reutilizáveis e fáceis de manter.

Qual a diferença entre JDK, JRE e JVM?

A diferença entre eles está no propósito: a JVM roda o seu código, o JRE fornece as bibliotecas necessárias para essa execução, e o JDK é o pacote completo com ferramentas para você programar, compilar e criar aplicativos.

O que são e quais as diferenças entre Classes Abstratas e Interfaces?

Classes Abstratas são modelos base que não podem ser instanciados e servem para compartilhar código e estrutura entre classes relacionadas. Interfaces são contratos que definem o que uma classe deve fazer, mas não como.

JavaScript

Qual é a diferença entre == (igualdade solta) e === (igualdade estrita)?

A diferença está na conversão de tipos. O operador == (igualdade solta) converte os tipos dos valores antes de comparar, enquanto o === (igualdade estrita) exige que ambos tenham o mesmo valor e o mesmo tipo de dado.

O que é uma Closure (fechamento)?

Uma Closure (ou fechamento) é a capacidade que uma função tem de "lembrar" e acessar as variáveis e os parâmetros do seu escopo léxico (o ambiente onde foi criada), mesmo depois que a função externa terminou de ser executada.

O que são Promises e como funcionam?

Uma Promise (promessa) é um objeto em JavaScript que representa a eventual conclusão (ou falha) de uma operação assíncrona. Ela permite que seu programa continue executando enquanto aguarda o resultado de uma tarefa em segundo plano, evitando travamentos e o uso complexo de callbacks.

O que é o Event Loop?

O Event Loop (ou laço de eventos) é o mecanismo central que permite a linguagens como o JavaScript executar operações assíncronas e não bloqueantes. Ele funciona como um "gerente", monitorando continuamente a execução do código, processando eventos e chamando tarefas enfileiradas para garantir que o programa não congele
